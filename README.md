# Азкары

Утренние и вечерние азкары, азкары после намаза, достоверные дуа и пятница (сура «Аль-Кахф», салават).
Арабский текст, транскрипция, перевод, источник и аудио.

- `azkar.html` — исходник приложения; `node build.js` собирает `index.html` (страница для GitHub Pages и Telegram Mini App).
- `audio/` — записи: «Крепость мусульманина» (hisnmuslim.com) и Мишари Рашид аль-Афаси (everyayah.com, quran.com), обрезаны по тексту карточек (`tools/`).
- `kahf.json` — текст суры «Аль-Кахф» (Tanzil) и перевод Э. Кулиева.
